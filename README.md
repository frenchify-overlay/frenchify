# Frenchify

A Hypixel Bed Wars overlay for Minecraft 1.8.9 on Apple Silicon Macs. It works with Lunar Client and Badlion Client.

Original by FrenchyBye. This is the macOS version.

## What it does

- TAB overlay with stats, Urchin tags and a Sniper score
- Chat alerts and a session HUD
- Item counter, height limit and Bed Wars info
- A small Mac app that sets everything up for you

It only shows information. It does not play the game for you.
